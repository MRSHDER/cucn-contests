# 赛事簿 · 设计艺术赛事工作台

依据学校竞赛目录整理设计艺术赛事，提供组合筛选、最多四项并排对比、浏览器收藏、截止日历、官方来源、后台核验、变更记录与新公告候选。

**在线访问：[CUCN赛事簿](https://cucn-contests.des750227.chatgpt.site)**

> 本项目由学生独立开发与维护，非南京传媒学院官方平台。赛事认定以学校最新通知为准。

## 当前部署

线上站点已开放访问，部署由 Sites 托管。本仓库公开源码和数据；线上部署另行保留管理员写入授权，普通访客仅可浏览赛事数据。

**许可证：** 暂未选择开源许可证。在添加许可证之前，代码可以公开查看，但未经作者同意不授予复制、修改或再分发的权利。

后续如向学校交付，应先确认维护主体、授权方式、目录使用范围和运行费用。

## 学校复用配置

- `config/site.mjs`：站点名称、学校、主题范围、时区、官方域名登记表及主页来源。
- `public/data.mjs`：初始赛事及学校目录条目，含PDF页码、序号和目录备注。更换学校时须整体替换并重新核验认定。
- `public/index.html` / `style.css` / `app.mjs`：原生交互前端。默认不限制个人参赛、免外出、免寄送或观察目录；使用者自行选择。
- `server/state.mjs`：数据校验、逐字段依据、变更记录、R2条件写入。
- `server/collector.mjs`：官方网页正文抓取、指纹监测和新公告候选提取，失败时保留旧记录。
- `server/source-archive.mjs`：正文版本存档、前后差异与待核验队列；抓取成功和核验通过分别记录。
- `server/api.mjs`：快照、扫描、核验写入和任务状态接口。
- `docs/AUTOMATION.md`：无人值守核验工作流。

## 更新方式与准确性

后台定时任务每6小时扫描官方来源，再依据官方简章核验结构化字段和发现新赛事；开放页面每分钟读取最新快照。无需用户开着网页。它不是全网即时搜索引擎，也不保证发现全部变更。动态页面、反爬或访问失败会标记，已核验数据不会因失败被抹掉。

原文变化仅生成待核验记录。只有附有字段原文依据的核验写入才改变赛事字段。官方报名、缴费、AI工具规则、著作权约定及学校校内截止应由使用者最终核对。

学校认定等级取自已导入目录，主赛/专项、国赛/省赛、竞赛目录/观察目录分别标注。学校认定不等于统一行业排名。

## 开发与部署

Node.js >=22.13，使用pnpm及锁文件。安装、预览、构建由Sites标准工作流执行；`node --test tests/*.test.mjs`运行数据、筛选和后台写入测试。`pnpm build`构建Vinext/Cloudflare Worker及前端静态资源。

`.openai/hosting.json`中R2逻辑绑定为`BUCKET`，由Sites配置实际资源。仓库中的`project_id`已置空，独立部署时填写自己的Sites项目ID。不要将已有站点ID、R2内容、浏览器收藏、凭据复制为新的开源模板；独立部署必须分配自己的资源。

## 私有访问与学校部署

当前写入接口依赖Sites的owner-only访问边界，服务任务使用每次从Sites获取的专属服务访问凭据。**不能把当前访问策略直接改成公开来提供学校公用服务。** 面向多人/公开部署前，应添加管理员写入授权及独立的服务任务身份，普通读者只能读赛事。必须确认访问控制、个人收藏隔离和更新权限后再开放。

当前收藏只保存在使用者浏览器，不上传共享库，支持导入导出。赛事库不包含原作者的姓名、专业身份或个人筛选偏好。保留备份格式向后兼容标识不代表收集用户身份。

## 密钥与运行成本

本项目不含模型API密钥，官方网页扫描不调用付费生成式API。语义核验由关联的ChatGPT定时任务执行，其可用性受账号任务能力约束。R2、托管和未来独立任务服务的用量按部署平台规则管理；学校自行部署时应另行配置调度器。不得把会话服务token提交到仓库。
